# Code of Conduct

This repository supports a scholarly computational-law experiment.

Participants are expected to:

- use respectful, precise, evidence-based communication;
- distinguish conceptual disagreement from personal criticism;
- avoid misleading claims about legal, regulatory, or institutional effects;
- disclose conflicts of interest where relevant;
- preserve the implementation-independent nature of the experiment.

Unacceptable conduct includes harassment, personal attacks, discriminatory conduct, intentional misrepresentation of results, or attempts to present this repository as legal advice.

Maintainers may remove issues, pull requests, or comments that violate these standards.
