# Security Policy

This repository contains synthetic scenarios only. It should not process personal data, confidential information, regulated financial data, or customer records.

## Reporting

If you identify a vulnerability or a misleading behavior that could cause users to misinterpret the experiment, open a private security advisory or contact the maintainers.

## Scope

In scope:

- unsafe file handling;
- command execution vulnerabilities;
- misleading output that could affect research integrity;
- accidental inclusion of confidential data.

Out of scope:

- legal advice requests;
- requests to adapt the repository to live compliance workflows;
- requests to certify institutional admissibility for real-world actions.
